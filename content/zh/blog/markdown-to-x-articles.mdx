X Articles 并不支持 Markdown。MD2X 补上了这道鸿沟——用 Markdown 写作，复制为富文本，再粘贴进 X Articles，格式原样保留。

## 问题：X Articles 不支持 Markdown

X Articles 使用的是一套专有富文本编辑器。如果你和大多数开发者、技术写作者一样习惯用 Markdown，就会遇到这些麻烦：

- 直接粘贴原始 Markdown，星号、井号、方括号会原样显示，而不是排版后的文字
- 手动逐个调整标题、加粗和链接，每篇文章要多花 10–20 分钟
- 代码块丢失语法高亮，变成难以阅读的纯文本
- 表格、Mermaid 图表等结构化内容根本无法表达
- 发布前无法预览文章最终长什么样

## 解决方案：MD2X 把 Markdown 转成 X Articles 富文本

MD2X 是一款免费、运行在浏览器里的工具，能把标准 Markdown 转成专为 X Articles 优化、可直接粘贴的富文本。它自动处理：

- **标题**（h1–h3）转为 X Articles 的标题样式
- **粗体、斜体、删除线**在剪贴板中保留
- **链接**变成 X Articles 里可点击的超链接
- **有序和无序列表**保留结构与层级
- **代码块**渲染为带语法高亮的 PNG 图片（X Articles 的变通方案）
- **表格**渲染为可内嵌粘贴的格式化图片
- **Mermaid 图表**渲染为流程图/时序图 PNG

## 如何把 Markdown 转成 X Articles

### 1. 编写或导入 Markdown

打开 MD2X 编辑器，用标准 Markdown 开始写作，也可以导入已有的 `.md` 文件。右侧面板会实时预览文章在 X Articles 里的效果。

### 2. 复制格式化后的内容

点击“复制标题”拿到文章标题，再点“复制正文”拿到完整的格式化内容。MD2X 会把一切转成 X Articles 能识别的富文本——无需手动排版。

### 3. 粘贴进 X Articles 并发布

打开 X Articles 编辑器，按 Cmd+V（或 Ctrl+V），格式化好的文章立刻出现。再从 Assets 面板粘贴代码块或图表图片，加上封面图，点发布即可。

**Markdown 输入：**

