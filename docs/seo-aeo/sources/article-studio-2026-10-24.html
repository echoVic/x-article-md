How to convert Markdown to an X Article

  1. Paste or import your Markdown. Use a .md file from Obsidian, VS Code or any other editor. The first H1 or frontmatter title becomes the article title, and you can edit it above the preview.
  2. Attach local images. A browser cannot open the image paths inside a Markdown file on its own, so choose the image folder once in Images & diagrams. Only images the article references are attached.
  3. Review the preview. Mermaid code blocks are rendered as PNG images. Tables stay native or become PNG images. Anything that would lose content is flagged with a line link to the source.
  4. Copy or create a draft. Copy the title and formatted body into X, or use the free Chrome companion to create an unpublished X Article draft with images in place. You publish from X.

What converts

  • Formatted text: H2 and H3 headings, bold, italic, strikethrough, links, single-level lists, quotes, dividers and code blocks.
  • Tables: kept as a native Markdown table in the draft, or rendered as PNG images when you paste instead. Adding tables to X Articles
  • Mermaid diagrams: flowcharts and other Mermaid code blocks become PNG images at 2× resolution. Mermaid diagrams in X Articles
  • Images: local or public PNG, JPEG and WebP files, placed where they appear in your Markdown. Markdown images in X Articles

Not converted yet: footnotes, raw HTML, GIF, SVG, video and image ALT text. These are listed in the preview instead of being dropped silently. The full format guide covers the details.

Frequently asked questions

Is Article Studio free?

Yes. The editor, copying, ZIP export and the Chrome companion are free to use.

Do I need the Chrome extension?

No. You can copy the title and body without it. The companion is only needed to upload images and create the draft automatically.

Where is my article stored?

In this browser. Markdown and images are prepared locally. They are sent to X only when you confirm draft creation in the companion, or straight from Create X draft if you turned on that option in the companion. See the privacy policy.

Does it publish to X for me?

No. It creates a draft in your signed-in X account, and you review and publish it in X. Your account needs access to X Articles, which X controls. X can change its editor, so check each draft before publishing.
