## P0 — 第一阶段：补齐基础（1-2 周）

### 任务 #1：补充 h4-h6 标题支持

- **问题**：`lib/markdown.ts` 仅支持 h1-h3，h4-h6 无法渲染
- **期望**：`####` 至 `######` 正常渲染，预览区显示对应层级标题样式
- **优先级**：P0（高）
- **工作量**：~0.5 天
- **技术指引**：
  - `lib/markdown.ts`：`headingPattern` 正则 `/^(#{1,3})\s+(.+)$/` → `/^(#{1,6})\s+(.+)$/`，类型扩展 `4|5|6`
  - `components/article-preview.tsx`：增加 h4-h6 渲染逻辑和 Tailwind 样式
  - `tests/markdown.test.ts`：新增 h4-h6 解析测试用例

### 任务 #2：支持斜体语法

- **问题**：不支持 `*italic*` 基础 Markdown 语法
- **期望**：`*斜体文字*` 在预览区以 `<em>` 样式渲染，不影响现有 `**粗体**` 功能，支持嵌套 `**粗体中的*斜体***`
- **优先级**：P0（高）
- **工作量**：~0.5 天
- **技术指引**：
  - `lib/markdown.ts` — `parseInline` 函数：token 类型增加 `italic`；正则先匹配 `**bold**`，再匹配 `*italic*`
  - `components/article-preview.tsx`：`<em>` 元素渲染 + Tailwind `italic` 样式
  - `tests/markdown.test.ts`：斜体 + 粗斜体组合测试

### 任务 #3：支持引用块语法

- **问题**：不支持 `>` 引用块，长文中高频使用
- **期望**：连续 `> ` 行合并为单个 `<blockquote>`，引用块内支持行内格式（粗体、斜体、链接等）
- **优先级**：P0（高）
- **工作量**：~0.5 天
- **技术指引**：
  - `lib/markdown.ts`：`ArticleBlock` 增加 `blockquote` 类型；新增 `blockquotePattern = /^>\s?(.+)$/`
  - `components/article-preview.tsx`：`<blockquote>` 元素 + 左边框灰色样式
  - `tests/markdown.test.ts`：单行引用 + 多行连续引用测试

### 任务 #4：支持图片语法

- **问题**：不支持 `![alt](url)` 图片引用
- **期望**：行内图片和块级图片正常渲染，加载失败显示 alt 占位文字，max-width 100% 防溢出
- **优先级**：P0（高）
- **工作量**：~0.5 天
- **技术指引**：
  - `lib/markdown.ts`：`ArticleBlock` 增加 `image` 类型；`parseInline` 增加 `![alt](url)` 匹配
  - `components/article-preview.tsx`：`<img>` 标签渲染
  - `tests/markdown.test.ts`：行内图片 + 块级图片测试

### 任务 #5：分栏可拖拽调整宽度

- **问题**：编辑器和预览区的分栏分割线不可拖拽，宽度固定
- **期望**：拖拽分割线动态调整分栏比例，有拖拽视觉反馈，最小/最大宽度约束（20%-80%）
- **优先级**：P0（中）
- **工作量**：~1 天
- **技术指引**：
  - `components/editor-page.tsx`：`mousedown/mousemove/mouseup` 事件驱动拖拽
  - 动态调整 CSS `grid-template-columns` 或 `resize` 状态变量
  - `mouseup` 时清理全局监听器

### 任务 #6：导入/导出 .md 文件

- **问题**：无法导入本地 `.md` 文件，也无法导出编辑内容为 `.md`
- **期望**：导入按钮读取 `.md` 文件并替换编辑器内容；导出按钮下载当前内容为 `.md` 文件
- **优先级**：P0（中）
- **工作量**：~0.5 天
- **技术指引**：
  - 导入：隐藏 `<input type="file" accept=".md">` + `FileReader.readAsText()`
  - 导出：`new Blob()` + `URL.createObjectURL()` + `<a download>` 触发
  - 文件名默认首行标题或 `untitled.md`；大小限制 1MB

## P1 — 第二阶段：AI 增强（2-4 周）

### 任务 #7：AI 文章润色

- **问题**：无 AI 写作辅助，竞品 Typefully/TweetHunter 均含此功能
- **期望**：选中文本后可调用 AI 润色/改写，结果可预览、对比、接受/拒绝
- **优先级**：P1（高）
- **工作量**：~3 天
- **建议方案**：API Route 调用 DeepSeek/OpenAI；前端展示 diff 对比
  
### 任务 #8：AI 中英互译

- **问题**：当前仅支持手动切换语言界面，不支持内容翻译
- **期望**：一键翻译编辑器全文（中→英 / 英→中），保持 Markdown 格式
- **优先级**：P1（中）
- **工作量**：~2 天

### 任务 #9：AI 文章摘要

- **问题**：无法生成文章摘要用于 X Articles 的标题/开头钩子
- **期望**：生成 1-2 句摘要，可直接复制到 X 发布
- **优先级**：P1（中）
- **工作量**：~1 天

### 任务 #10：编辑器语法高亮

- **问题**：编辑区纯文本无语法着色
- **期望**：集成 CodeMirror 或 Monaco，Markdown 语法高亮
- **优先级**：P1（中）
- **工作量**：~2 天
- **注意**：需权衡 bundle size，建议 CodeMirror（更轻量）

## P2 — 第三阶段：生态建设（1-2 月）

### 任务 #11：暗色模式手动切换

- **问题**：暗色模式仅跟随系统，用户无法手动切换
- **期望**：工具栏增加亮/暗/自动三态切换按钮
- **优先级**：P2（中）
- **工作量**：~1 天

### 任务 #12：多草稿管理

- **问题**：仅支持单草稿自动保存（localStorage）
- **期望**：草稿列表（新建/重命名/删除/切换），附带时间戳和首行预览
- **优先级**：P2（低）
- **工作量**：~2 天

### 任务 #13：移动端深度优化

- **问题**：响应式有基础但移动端写作体验不佳
- **期望**：小屏幕下切换为上下分栏（非左右），工具栏适配触屏，字号可调
- **优先级**：P2（中）
- **工作量**：~3 天

### 任务 #14：PWA 离线支持

- **问题**：无离线能力，完全依赖网络
- **期望**：Service Worker + manifest，离线可用，可安装到桌面
- **优先级**：P2（低）
- **工作量**：~2 天
